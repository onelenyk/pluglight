Your cable knows
what your agent is doing.

PlugLight turns the LED on your MacBook's MagSafe cable into a status light for Claude Code and other AI coding agents.

Working
$ curl -fsSL https://pluglight.onelenyk.dev/install.sh | sh

Free and open source · macOS 13+ · Mac with MagSafe 3 (Apple Silicon)

One glance is enough.

The hardware can show green, orange and off, so PlugLight uses rhythm too. With several agents, the most important state wins.

Workingsolid orange
Waiting for youslow orange blink — permission or question
Errorfast orange blink
Donegreen for 10 minutes
Idlenormal charging indicator

Install once. Forget about it.

A tiny menu bar app, a small helper and a few hooks. No accounts, no network, no tracking.

1
Run the command

It downloads the latest release, verifies its checksum and puts PlugLight in Applications.

2
Approve the helper

Only root may talk to the charging controller, so a small helper asks for your password once.

3
Connect Claude Code

PlugLight adds its hooks to ~/.claude/settings.json and leaves your other hooks alone.

Questions

Which Macs are supported?

Any Mac with a MagSafe 3 port: MacBook Air M2 and later, MacBook Pro 14″ and 16″ from 2021 onward, running macOS 13 or later. Tested on a MacBook Pro M4 Pro with macOS 26.

Does it affect charging?

No. PlugLight writes a single indicator key in the System Management Controller (ACLC). Charging works exactly as before, and nothing persists across a reboot or a re-plug.

Why a terminal command instead of a download button?

PlugLight is free and not signed with a paid Apple Developer ID. macOS blocks unsigned apps downloaded by a browser; files fetched with curl are not quarantined, so the app simply opens. Prefer a zip? Grab it from GitHub Releases and use “Open Anyway” in System Settings → Privacy & Security.

What does the root helper do?

It reads small state files written by agent hooks and sets the LED. It makes no network connections and runs no other programs. When you quit the app, it hands the LED back to macOS within a couple of seconds. Details are in SECURITY.md.

Can I use it with other agents?

Claude Code is supported out of the box. Any agent with hooks can call pluglight hook busy|waiting|done|error|idle and pass its event on stdin. Contributions for more agents are welcome.

How do I uninstall it?

curl -fsSL https://pluglight.onelenyk.dev/install.sh | sh -s -- uninstall removes the hooks, the helper and the app.
